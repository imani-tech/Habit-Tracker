# Habit tracker
--- 
The app should let the user:

1. Add Habit
2. Choose a category.
3. Mark the habit as done for today.
4. Track the current streak.
5. Show how many times the habit has been completed.
6. Delete a habit.
7. Save everything in localStorage.
8. Show a simple dashboard at the top
